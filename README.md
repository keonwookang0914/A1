# ⚒️기능
- 캐릭터가 사용 가능한 아이템 및 다른 아이템을 보관 가능한 인벤토리 시스템
- HUD를 통한 플레이어 상태 확인 가능
- 플레이어와 상호작용이 가능한 우주선 내부 시스템
- G키를 통한 아이템 버리기 가능
- 왼쪽 마우스 키가 다양한 행동에 매핑(공격, 아이템 줍기)
- 플레이어가 아이템을 파밍할 수 있는 외부 맵 생성기 존재
